3. 처리를 맡기는 곳과 국외 이전

회원 명단을 광고주나 게임사에 제공하거나 판매하지 않습니다. 법령에 따른 요청이 있는 경우는 예외입니다. 사이트 운영을 위해 아래 업체에 처리를 맡기며, 서버가 해외에 있을 수 있습니다.

GitHub, Inc.미국. 페이지 호스팅. 접속 시 IP 주소, 접속 시각, 브라우저 정보가 전달될 수 있습니다. 보관 기간은 GitHub 개인정보 처리방침을 따릅니다.
Telegraph (telegra.ph)피드백 글의 저장과 공개. 해외 서비스이며, 글을 올리는 시점에 이름, 제목, 내용이 전송됩니다. 삭제를 요청하면 이 사이트에서 글 삭제를 진행합니다.

사이트 이용을 거부하면 위 호스팅과 방문 집계는 이루어지지 않습니다. 피드백을 쓰지 않으면 Telegraph로는 글이 전송되지 않습니다.

4. 구글 로그인 회원가입

현재 구글 로그인을 제공하지 않으며, 구글 계정 정보를 수집하지 않습니다. 회원가입을 열기 전에 실제로 받는 항목과 서버가 있는 국가를 이 방침에 고친 뒤 공개합니다.

기능을 연 뒤에는 회원 식별, 로그인 유지, 회원 전용 이벤트 참여와 중복 참여 확인을 위해 다음을 처리할 예정입니다.

  • 구글 계정 이메일
  • 구글 계정 식별값
  • 이 사이트가 부여하는 회원 번호, 가입 시각, 이벤트 참여 기록
  • 구글 표시 이름과 프로필 사진은 그 권한을 켠 경우에만

비밀번호, 생년월일, 전화번호, 주민등록번호는 회원가입 항목으로 받지 않습니다. 만 14세 이상만 가입할 수 있습니다. 보관은 탈퇴 시까지이며, 탈퇴하면 지체 없이 삭제합니다. 로그인이 없으면 회원 전용 이벤트에는 참여할 수 없습니다.

그때의 보관과 로그인 처리는 Supabase, 계정 확인은 Google에 맡깁니다. 두 서비스의 서버 국가, 연락처, 거부 방법은 기능을 열 때 이 방침에 구체적으로 적습니다.

5. 보유와 삭제

목적 달성, 보유 기간 경과, 이용자의 삭제·탈퇴 요청이 있으면 지체 없이 삭제합니다. 피드백 글은 Telegraph에서 삭제합니다. 측정기 선택값은 이용자 기기에만 있으므로 브라우저에서 지웁니다. 다른 법령에 따라 보관해야 하는 정보는 그 기간만 따로 보관한 뒤 삭제합니다.

사이트 접속은 HTTPS를 사용합니다. 회원 기능을 열 때는 본인 정보만 보이게 접근을 제한하고, 관리자 계정에는 2차 인증을 둡니다. 회원 명단과 로그인 비밀키는 공개 저장소에 올리지 않습니다.

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 피드백 글과, 나중에 생기는 회원 정보에 적용됩니다. 요청은 보호책임자 이메일로 하면 됩니다. 회원 기능이 열리면 로그인한 뒤 탈퇴 버튼으로도 삭제할 수 있게 합니다.

만 14세 미만 아동의 개인정보를 회원 가입으로 받지 않습니다. 피드백 등에 아동의 개인정보가 올라온 사실을 알게 되면 삭제합니다.
